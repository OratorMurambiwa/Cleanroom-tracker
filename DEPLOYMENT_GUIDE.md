# 🚀 Cleanroom Tracker - Render Deployment Guide

## Overview
This guide will walk you through deploying your Cleanroom Tracker Django application on Render, a modern cloud platform that makes deployment simple and reliable.

## 📋 Prerequisites
- [ ] GitHub repository with your Cleanroom Tracker code
- [ ] Render account (free tier available)
- [ ] Basic understanding of Django deployment

## 🔧 Step-by-Step Deployment

### **Step 1: Prepare Your Repository**

1. **Ensure all deployment files are committed:**
   ```bash
   git add .
   git commit -m "Add Render deployment configuration"
   git push origin main
   ```

2. **Verify these files exist in your repo:**
   - `render.yaml` - Render service configuration
   - `requirements.txt` - Python dependencies
   - `build.sh` - Build script
   - `Procfile` - Process definition
   - `backend/backend/settings_production.py` - Production settings

### **Step 2: Create Render Account**

1. Go to [render.com](https://render.com)
2. Sign up with GitHub (recommended)
3. Verify your email address

### **Step 3: Deploy Using Blueprint**

1. **Click "New +" in your Render dashboard**
2. **Select "Blueprint"**
3. **Connect your GitHub repository**
4. **Select the repository: `Cleanroom-tracker`**
5. **Render will automatically detect `render.yaml`**
6. **Click "Apply" to start deployment**

### **Step 4: Configure Environment Variables**

After the initial deployment, configure these environment variables in your web service:

#### **Required Variables:**
- `SECRET_KEY` - Auto-generated by Render
- `DATABASE_URL` - Auto-configured from PostgreSQL service
- `REDIS_URL` - Auto-configured from Redis service
- `DEBUG` - Set to `False`

#### **Optional Variables:**
- `EMAIL_HOST` - SMTP server (e.g., `smtp.gmail.com`)
- `EMAIL_HOST_USER` - Your email address
- `EMAIL_HOST_PASSWORD` - Your email password
- `EMAIL_PORT` - SMTP port (usually `587`)

### **Step 5: Monitor Deployment**

1. **Watch the build logs** for any errors
2. **Check service health** - should show "Healthy"
3. **Test your application** at the provided URL
