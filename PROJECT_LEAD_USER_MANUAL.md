## Getting Started

### First Time Login
1. **Access the System**: Navigate to the Cleanroom Tracker login page
2. **Enter Credentials**: Use your assigned username and password
3. **Select Role**: Choose "projectlead" from the role dropdown
4. **Dashboard Access**: Upon successful login, you'll be redirected to your project lead dashboard

### System Requirements
- **Browser**: Modern web browser (Chrome, Firefox, Safari, Edge)
- **Internet**: Stable internet connection
- **Permissions**: Full access to create, manage, and oversee projects and teams

## System Overview

The Cleanroom Tracker is a comprehensive project management system designed specifically for cleanroom operations. As a project lead, you have access to:

- **Project Management**: Create, manage, and oversee all projects
- **Task Management**: Assign, monitor, and approve tasks
- **Component Tracking**: Manage component builds and progress
- **Team Management**: Assign technicians and manage team members
- **Communication**: Lead team discussions and coordinate efforts
- **Quality Control**: Review and approve completed work
- **Reporting**: Monitor project progress and team performance

## Lead Dashboard

### Overview
The lead dashboard is your central command center, providing a comprehensive view of all projects, team status, and pending approvals.

### Main Sections

#### 1. Active Projects
- **Project List**: Shows all projects you're managing
- **Progress Bars**: Visual representation of project completion
- **Quick Actions**: Create new projects and components
- **Project Details**: Click project names to view full information

#### 2. Component Builds
- **Component Status**: Current build progress for all components
- **Progress Tracking**: Visual progress indicators
- **Direct Access**: Click to view component details and tasks

#### 3. Pending Approvals
- **Task Review Queue**: Tasks completed by technicians awaiting approval
- **Quick Review**: Click tasks to review and approve/reject
- **Quality Control**: Ensure work meets project standards

### Dashboard Actions

#### Creating New Projects
1. Click **"New Project"** button
2. Fill in project details (name, description)
3. Optionally link to existing components
4. Add team members
5. Click **"Create Project"** to save

#### Creating New Components
1. Click **"New Component"** button
2. Enter component name and specifications
3. Link to relevant projects
4. Set initial progress status
5. Click **"Create Component"** to save

## Task Review & Approval

### Task Review Process
When technicians complete tasks, they require your review and approval.

#### Review Page Access
- **Pending Approvals**: Dashboard shows tasks awaiting review
- **Direct Links**: Click task titles to access review page
- **Quick Overview**: See task status and completion details

#### Review Process

##### 1. Task Assessment
- **Completion Status**: Verify task meets requirements
- **Quality Check**: Review work quality and standards
- **Documentation**: Check submitted notes and attachments
- **Timeline**: Verify completion within deadline

##### 2. Approval Decision
- **Approve**: Accept completed work and mark task approved
- **Request Changes**: Return task with modification requirements
- **Reject**: Reject work that doesn't meet standards
- **Add Comments**: Provide feedback and guidance

##### 3. Post-Approval Actions
- **Progress Update**: Component and project progress automatically updates
- **Team Notification**: System notifies relevant team members
- **Documentation**: Update project records and documentation

#### Quality Control Guidelines
- **Standards Compliance**: Ensure work meets cleanroom standards
- **Documentation**: Verify proper record keeping
- **Safety**: Confirm safety protocols were followed
- **Efficiency**: Check that work was completed efficiently
