## Getting Started

### First Time Login
1. **Access the System**: Navigate to the Cleanroom Tracker login page
2. **Enter Credentials**: Use your assigned username and password
3. **Select Role**: Choose "technician" from the role dropdown
4. **Dashboard Access**: Upon successful login, you'll be redirected to your technician dashboard

### System Requirements
- **Browser**: Modern web browser (Chrome, Firefox, Safari, Edge)
- **Internet**: Stable internet connection
- **Permissions**: Ensure you have access to the assigned projects and components

## System Overview

The Cleanroom Tracker is a comprehensive project management system designed specifically for cleanroom operations. As a technician, you have access to:

- **Project Management**: View and work on assigned projects
- **Task Management**: Complete and track assigned tasks
- **Component Tracking**: Monitor component builds and progress
- **Communication**: Message team members and project leads
- **Asset Management**: Look up component and asset information
- **Calendar**: Manage reminders and deadlines

## Asset Lookup

### Asset Lookup Feature
Available on the Components page

#### How to Use

##### 1. Upload Excel File
- **File Format**: Must be .xlsx format
- **Column Requirements**: Must contain "Asset Type" column
- **File Size**: Check with administrator for limits

##### 2. Search Options

###### Asset Type Search
- **Partial Matching**: Enter part of asset type name
- **Example**: "BTM" will find "BTM1234", "BTM-Sensor"
- **Case Insensitive**: Search works regardless of capitalization

###### Assembly Number Search
- **Exact Matching**: Enter complete assembly number
- **Example**: "ASSY-001" must match exactly
- **Minimum Length**: Requires at least 2 characters

##### 3. Search Process
1. **Select Search Field**: Choose Asset Type or Assembly Number
2. **Enter Query**: Type your search term
3. **Click Search**: Execute the search
4. **View Results**: Review matching assets

#### Search Tips
- **Asset Type**: Use partial text for broader results
- **Assembly Number**: Use exact text for precise results
- **File Management**: Upload new files or use existing ones
- **Column Names**: Ensure Excel file has correct column headers

- **Refresh Page**: Try refreshing the browser

- **Browser Cache**: Clear browser cache and cookies
- **Contact Admin**: Report persistent icon issues

#### 2. Tasks Not Loading
- **Check Permissions**: Verify you have access to the component
- **Refresh Page**: Reload the page
- **Check Console**: Look for error messages in browser console
- **Contact Support**: Report technical issues

#### 3. File Upload Issues
- **File Format**: Ensure file is .xlsx format
- **File Size**: Check if file exceeds size limits
- **Column Names**: Verify Excel file has correct column headers
- **Permissions**: Ensure you have upload permissions

#### 4. Search Not Working
- **File Uploaded**: Ensure Excel file is available
- **Column Names**: Check if search field exists in file
